# Git Conventions

- If you group changes into commits or write a commit message, read [Commits](references/commits.md).
- If you name a branch, read [Branches](references/branches.md).
- If you write or update a PR title or body, or prepare PR evidence, read [Pull Requests](references/pull-requests.md).
